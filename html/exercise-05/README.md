# Section vs Article

`<section>` is used to group related information.

```html
<section>
  <h2>About Me</h2>
  <p>My name is Ana.</p>
</section>
```

`<article>` is used for a complete piece of content, like a post or news.

```html
<article>
  <h2>My First Day</h2>
  <p>Today was a great day!</p>
</article>
```

**Simple difference:**
`<section>` = group of content.
`<article>` = independent content.
