# HTML Text Semantics

## `<strong>` vs `<b>`

Both can make text look bold, but their meaning is different.

- `<strong>` → shows that the text is important.
- `<b>` → highlights text visually without adding importance.

## `<em>` vs `<i>`

Both can make text look italic, but they have different purposes.

- `<em>` → adds emphasis to the meaning.
- `<i>` → visually separates text without adding emphasis.

### In short

Use `<strong>` and `<em>` when **meaning matters**.
Use `<b>` and `<i>` when the **visual presentation** is the main purpose.
