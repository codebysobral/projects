# My Git Aliases

| Alias | Original Command | Reason |
|-------|------------------|--------|
| st | git status | I used `git status` constantly to check repository changes. |
| co | git checkout | Frequently used to switch branches. |
| br | git branch | Makes branch management faster. |
| cm | git commit -m | Reduces typing when creating commits. |
| lg | git log --oneline --graph --decorate --all | Provides a compact and readable commit history. |

[alias]
    st = status
    co = checkout
    br = branch
    cm = commit -m
    lg = log --oneline --graph --decorate --all
