## My Experience with `origin` and `upstream`

Setting up `origin` and `upstream` together was a useful learning experience.

* `origin` points to my fork of the repository.
* `upstream` points to the original repository.

This setup makes it easier to keep my fork synchronized with the original project and to create Pull Requests from my fork.

Overall, this was a simple but valuable first experience with the open-source contribution workflow.
