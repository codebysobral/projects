# GitHub Pages: Special vs. Regular Repository

GitHub Pages can publish websites in two ways.

## Special Repository (`username.github.io`)

A repository named exactly `username.github.io` becomes your main GitHub Pages site.

Example:

- Repository: `codebysobral/codebysobral.github.io`
- URL: `https://codebysobral.github.io/`

This is usually where people host their personal website or portfolio.

## Regular Repository

Any other repository can also use GitHub Pages.

The difference is that the website is published under the repository name.

Example:

- Repository: `codebysobral/my-project`
- URL: `https://codebysobral.github.io/my-project/`

This is a good choice for project pages or documentation.

## Summary

The only real difference is the URL.

- `username.github.io` → your main website.
- Any other repository → a website inside `/repository-name/`.

Both use GitHub Pages—the repository name determines where the site is published.
